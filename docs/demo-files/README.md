и в окне «Банк запросил данные», чтобы пройти сценарии без настоящих документов.

## Что проверено на стенде

Заявка с этими файлами доходит до сотрудника банка (статус «Ручная проверка» с баллом скоринга):

| Продукт | Что приложить |
|---|---|
| Экспресс-кредит, кредит для ООО | паспорт и согласие |
| Оборотный кредит | + бухгалтерская отчётность |
| Кредит до 1 млн, овердрафт | + выписка по расчётному счёту (для овердрафта ещё заполнить счёт и РКО в анкете) |
| Покупка бизнеса | + документы продукта и отчёт об оценке (его банк запросит отдельно) |

Залоговые продукты, ипотеку и кредит для селлеров целиком не прогоняли: файлы для них сделаны по описанию
парсеров воркера, этим продуктам нужны ещё заполненные поля анкеты.

## Почему заявка идёт к сотруднику, а не одобряется сама

Воркер не может проверить, что картинка паспорта настоящая, поэтому заявки с обычными файлами отправляет
на ручную проверку. Автоодобрение работает только на подписанных демо-образцах: подпись привязана
к конкретной заявке, поэтому заранее такой файл сделать нельзя. Как их создать — в разделе
«Демонстрация автоодобрения» в [worker/README.md](../../worker/README.md); для этого нужен ключ
`WORKER_DEMO_ATTESTATION_KEY` в `.env` (по умолчанию пустой).

## Если делаете свои файлы

Воркер читает только PDF с текстовым слоем (не фото и не скан):

- **бухгалтерская отчётность** — строки вида `Выручка 2110 48000` с одним числом в строке, заголовок
  «Отчёт о финансовых результатах за 2025 г.» и строка «Единица измерения: тыс. руб.»;
- **выписка по счёту** — таблица через `;` с заголовком `Дата;Поступление;Списание;Остаток`, в каждой
  строке либо поступление, либо списание, остаток сходится; для овердрафта и кредитной линии нужно
  не меньше 6 месяцев;
- **отчёт маркетплейса** — таблица через `;` с заголовком `period;sales;returns;payouts`;
- **отчёт об оценке** — «Дата оценки: ДД.ММ.ГГГГ» и «Рыночная стоимость: 8 500 000 руб.».

Загружать можно только PDF, JPG и PNG до 10 МБ. Если приложить два файла одного вида, воркер не прочитает
ни один — заменяйте файл кнопкой «Заменить», она удаляет прежний.
