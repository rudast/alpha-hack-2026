================================================================================
ИСТОЧНИКИ ДАННЫХ ДЛЯ КРЕДИТНОГО КОНВЕЙЕРА МСП (АЛЬФА-ХАК 2026)
================================================================================

1. Бухгалтерская отчетность (только ООО / АО):
   - Портал: ГИР БО ФНС РФ (Государственный информационный ресурс)
   - URL: https://bo.nalog.ru/
   - Открытые данные: https://bo.nalog.ru/opendata
   - Формат: JSON / XML / CSV
   - Извлекаемые формы: Баланс (Ф-1), Отчет о финрезультатах (Ф-2)

2. Регистрация и проверка компании (ООО и ИП):
   - Портал: Сервис ЕГРЮЛ/ЕГРИП ФНС РФ
   - URL: https://egrul.nalog.ru/
   - Открытые наборы: https://data.nalog.ru/opendata/
   - Извлекаемые данные: Дата регистрации, ОКВЭД, статус, адрес, директор

3. Налоговая дисциплина и благонадежность:
   - Портал: ФНС «Прозрачный бизнес»
   - URL: https://pb.nalog.ru/
   - Наборы данных: https://pb.nalog.ru/opendata.html
   - Извлекаемые данные: Среднесписочная численность, налоговые спецрежимы, долги

4. Транзакционная активность и расчетный счет (Ключевой источник для ИП):
   - Формат: Стандарт обмена «1С:Предприятие — Клиент Банка» (1CClientBankExchange)
   - Спецификация: https://v8.1c.ru/tekhnologii/obmen-dannymi-i-integratsiya/standarty-i-formaty/standart-obmena-s-klientom-banka/
   - Файл: 1c_to_kl.txt
   - Метод: локальный Python-парсер без внешних запросов

5. Эталонный ML-датасет кредитования малого бизнеса:
   - Название: U.S. Small Business Administration (SBA) Loan Default Dataset
   - URL: https://www.kaggle.com/datasets/mirichoi0218/sba-loan-default-dataset
   - Назначение: Первоначальное обучение и валидация алгоритма CatBoost

6. Макроэкономические показатели:
   - Портал: Банк России (ЦБ РФ)
   - API: https://www.cbr.ru/development/SXML/
   - Извлекаемые данные: Ключевая ставка ЦБ РФ (база для Risk-Based Pricing)
