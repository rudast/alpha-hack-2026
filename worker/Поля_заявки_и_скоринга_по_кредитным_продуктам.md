# Поля заявки и скоринга по кредитным продуктам

Oct 22, 2026 · @Ivan Duplo

Для всех 14 продуктов действует общий базовый набор полей; у каждого продукта поверх него — свои дополнительные поля и документы.

## Базовый набор (общий для всех 14 продуктов)

### 1. Клиентская часть — поля заявки и документы

| Поле формы | Куда пишется | Статус в схеме |
| --- | --- | --- |
| ИНН компании (ввод, далее авто-подтягивание через мок ЕГРЮЛ/ЕГРИП) | companies.inn | есть |
| Орг.-правовая форма (ИП/ООО) | companies.org\_type | есть |
| Наименование компании | companies.name | есть |
| ОКВЭД / вид деятельности | companies.okved | есть |
| Запрашиваемая сумма, ₽ | applications.amount | есть |
| Срок, мес. | applications.term\_months | есть |
| Цель кредита | applications.purpose | есть |
| Наличие залога (да/нет) | applications.form.collateral | нужно добавить |
| ФИО заявителя | users.full\_name | есть |
| Телефон | users.phone | есть |
| Email | users.email | есть |
| Должность в компании | applications.form.position | нужно добавить |

Документы (прикладываются в любом сценарии):

- Паспорт заявителя (скан 2–3 стр.)
- Согласие на обработку персональных данных и запрос в БКИ (скан/электронная подпись)
- Выписка из ЕГРЮЛ/ЕГРИП — опционально, если не подтягивается автоматически через мок

### 2. Скоринговые поля БД (используются при расчёте риска в любом сценарии)

| Поле | Источник | Статус в схеме |
| --- | --- | --- |
| companies.org\_type | форма | есть |
| companies.registration\_date (возраст бизнеса) | мок ЕГРЮЛ/ЕГРИП | есть (предлагается) |
| companies.okved (отраслевой риск) | форма / реестр | есть |
| companies.registry (руководитель, учредители, статус, адрес) | мок ЕГРЮЛ/ЕГРИП, «Прозрачный бизнес» | есть (предлагается) |
| companies.credit\_history (просрочки, текущие обязательства, число запросов за 90 дней) | мок БКИ | есть (предлагается) |
| companies.total\_debt, companies.equity, companies.debt\_to\_equity | бухгалтерская/налоговая отчётность (документ) | есть |
| companies.turnover | выписка по счёту (документ) | есть (предлагается) |
| companies.financials\_fetched\_at (свежесть данных) | служебное | есть (предлагается) |
| applications.amount, applications.term\_months, applications.product\_id | форма | есть |

Из документов в скоринг автоматически извлекаются: из выписки по счёту — обороты (turnover); из бухгалтерской отчётности/декларации — total\_debt, equity, debt\_to\_equity.

## Беззалоговые продукты, срок до 2 месяцев

Овердрафт, Возобновляемая кредитная линия (ВКЛ), Экспресс-кредит для бизнеса. Выдаются от оборотов по счёту, без запроса отчётности.

| Продукт | Доп. клиентские поля | Доп. документы | Доп. скоринговые поля БД |
| --- | --- | --- | --- |
| Овердрафт | Номер расчётного счёта; наличие РКО в банке-кредиторе | Выписка по расчётному счёту за 3–6 мес. | companies.turnover (из выписки); companies.form.has\_settlement\_account *(новое)*; среднедневной остаток на счёте *(новое)* |
| ВКЛ | Номер расчётного счёта; желаемый лимит линии | Выписка по расчётному счёту за 3–6 мес. | companies.turnover; волатильность оборотов (стандартное отклонение по месяцам) *(новое)* |
| Экспресс-кредит для бизнеса | — (минимальный пакет) | Паспорт + согласие на БКИ (из базового набора) — отчётность и выписка не запрашиваются | companies.credit\_history, companies.registry — решение принимается только по данным БКИ и реестров, без финансовых показателей |

Все три продукта используют только базовые клиентские поля без расширения формы, кроме явно указанных строк.

## Беззалоговые продукты, срок 3–18 месяцев

Кредит на пополнение оборотных средств, Кредит для селлеров маркетплейсов, Кредит для ИП, Кредит для ООО, Кредит до 1 млн ₽, Экспресс-кредит для бизнеса.

| Продукт | Доп. клиентские поля | Доп. документы | Доп. скоринговые поля БД |
| --- | --- | --- | --- |
| Кредит на пополнение оборотных средств | — | Бухгалтерский баланс и отчёт о прибылях и убытках за последний отчётный период (или налоговая декларация на УСН) | companies.equity, companies.total\_debt, companies.debt\_to\_equity (извлекаются из отчётности); companies.turnover |
| Кредит для селлеров маркетплейсов | Площадка (Wildberries / Ozon / Я.Маркет и т. п.); доля выручки через маркетплейс | Выгрузка/отчёт о продажах с площадки за 3–6 мес. | companies.marketplace\_turnover *(новое)*; companies.marketplace\_name *(новое)* |
| Кредит для ИП | — (фильтр по business\_type == «ИП», доп. полей нет) | базовый пакет | companies.org\_type == 'IP' |
| Кредит для ООО | — (фильтр по business\_type == «ООО», доп. полей нет) | базовый пакет | companies.org\_type == 'OOO' |
| Кредит до 1 млн ₽ | — | Выписка по счёту за 3 мес. (упрощённый пакет, без отчётности) | companies.turnover; порог по applications.amount ≤ 1 000 000 |
| Экспресс-кредит для бизнеса | — (минимальный пакет) | без расширения базового набора | companies.credit\_history, companies.registry |

«Кредит для ИП/ООО» и «Кредит до 1 млн ₽» — это не отдельные продукты с собственной формой, а result-фильтры по уже собранным базовым полям (org\_type, amount).

## Залоговые продукты, срок 24–84 месяца

Кредит на оборудование, Автокредит для бизнеса, Кредит под залог недвижимости/оборудования, Кредит на покупку завода/готового бизнеса, Ипотека для ИП, Ипотека для бизнеса (коммерческая недвижимость).

Общие для всей группы доп. поля (поверх базового набора): тип предмета залога (select), описание предмета залога, оценочная стоимость залога. Общие доп. документы: правоустанавливающие документы на залог.

| Продукт | Доп. клиентские поля | Доп. документы | Доп. скоринговые поля БД |
| --- | --- | --- | --- |
| Кредит на оборудование | Поставщик; реквизиты договора поставки | Договор купли-продажи / счёт-фактура на оборудование; спецификация | applications.form.collateral\_value *(новое)*; LTV = amount / collateral\_value *(расчётное)* |
| Автокредит для бизнеса | Марка, модель, год выпуска, VIN | ПТС/СТС или договор купли-продажи авто | applications.form.collateral\_value; LTV |
| Кредит под залог недвижимости/оборудования | Адрес объекта; кадастровый номер; площадь | Выписка из ЕГРН; технический паспорт; отчёт об оценке | applications.form.collateral\_value; LTV |
| Кредит на покупку завода / готового бизнеса | ИНН/наименование приобретаемого актива; краткое описание сделки | Бизнес-план; финансовая отчётность приобретаемого бизнеса; договор купли-продажи предприятия/долей | companies.form.target\_turnover, target\_profit *(новое, по целевому активу)*; collateral\_value; LTV |
| Ипотека для ИП | Адрес объекта; кадастровый номер; стоимость объекта; первоначальный взнос | Предварительный договор купли-продажи; выписка ЕГРН; отчёт об оценке | collateral\_value; LTV; applications.form.down\_payment *(новое)* |
| Ипотека для бизнеса (коммерческая недвижимость) | Адрес объекта; кадастровый номер; стоимость объекта; первоначальный взнос | Предварительный договор купли-продажи; выписка ЕГРН; отчёт об оценке | collateral\_value; LTV; down\_payment |

Для всех продуктов группы также действуют скоринговые поля из базового набора (отчётность, кредитная история, реестры) — срок и сумма здесь обычно требуют их в полном объёме.

## Залоговые продукты, срок до 24 месяцев

При коротком сроке с залогом целевые инвестиционные продукты (ипотека, покупка завода) не предлагаются — остаются базовый залоговый кредит и ВКЛ.

| Продукт | Доп. клиентские поля | Доп. документы | Доп. скоринговые поля БД |
| --- | --- | --- | --- |
| Кредит под залог недвижимости/оборудования (базовый) | Тип предмета залога; описание; оценочная стоимость | Правоустанавливающие документы на залог; выписка ЕГРН или спецификация оборудования | applications.form.collateral\_value; LTV |
| ВКЛ | Номер расчётного счёта; желаемый лимит линии | Выписка по расчётному счёту за 3–6 мес. | companies.turnover; волатильность оборотов |

Поля полностью совпадают с одноимёнными продуктами из других групп (см. выше) — здесь действует тот же набор, просто без дополнительных инвестиционных полей (бизнес-план, показатели целевого актива).

## Доработки схемы БД

Поля ниже встречаются выше, но в текущей схеме (`companies`, `users`, `applications`) их нет. Большинство можно положить в `applications.form` (jsonb) без миграции; в `companies` часть предложений уже значится как «предлагается» в data-model.md.

| Поле | Таблица | Тип | Комментарий |
| --- | --- | --- | --- |
| collateral | applications.form | boolean | есть ли залог по заявке |
| position | applications.form | text | должность заявителя в компании |
| collateral\_type, collateral\_description, collateral\_value, collateral\_address, collateral\_cadastre\_number | applications.form | jsonb-поля | данные о предмете залога — общие для всех залоговых продуктов |
| down\_payment | applications.form | bigint | первоначальный взнос (ипотечные продукты) |
| target\_business {inn, name, turnover, profit} | applications.form | jsonb | показатели приобретаемого актива (покупка завода/бизнеса) |
| marketplace\_name, marketplace\_turnover | companies | text, bigint (или jsonb companies.marketplace) | данные селлера на площадке; по аналогии с уже предложенным companies.registry |
| has\_settlement\_account | companies | boolean | наличие РКО в банке-кредиторе — влияет на скоринг овердрафта |
| turnover\_3m (оборот за последние 3 мес.) | companies | bigint | companies.turnover в data-model.md описан как годовой оборот; для овердрафта/ВКЛ нужен более короткий период — либо отдельное поле, либо расчёт из credit\_history/выписки |

Все перечисленные поля логично хранить в jsonb (`applications.form`, `companies.registry` или новый `companies.marketplace`), как это уже сделано для похожих данных в текущей схеме — отдельные колонки добавлять не требуется.
